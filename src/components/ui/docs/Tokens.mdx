# Tokens

A component reads tokens and nothing else. Two places define them:

- `src/lib/theme.ts`: the **color** tokens, which each Palette sets, and the **typography** tokens, which each Font sets.
  The Platform has its own Palette and Font, which Owners cannot pick.
- `src/styles/tokens.css`: everything no theme changes, like spacing, radii, shadows, motion and the type scale.

## Colors

| Token                  | For                                                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------- |
| `--color-bg`           | The page                                                                                 |
| `--color-surface`      | Cards, inputs and other raised surfaces                                                  |
| `--color-text`         | Body text                                                                                |
| `--color-text-muted`   | Supporting text: hints, dates, captions                                                  |
| `--color-accent`       | Fill of primary buttons and checked controls                                             |
| `--color-on-accent`    | Text and icons on an accent fill                                                         |
| `--color-accent-ink`   | Accent-colored text, the focus ring and selected outlines                                |
| `--color-soft`         | A quiet tint for hovers, chips and progress tracks                                       |
| `--color-border`       | The edge of inputs and unselected controls, at least 3:1 against the page and the card   |
| `--color-joy-1` to `3` | The decorative circles; text that lands on them still passes                             |
| `--color-danger`       | Error text and invalid edges                                                             |
| `--color-success`      | Success text                                                                             |
| `--color-scheme`       | `light` or `dark`, so native date pickers and dropdowns match the page                   |

## Contrast

Every pairing a component renders, measured for every Palette. `theme.test.ts` fails CI if one drops below its
minimum: 4.5:1 for text, 3:1 for edges, states and focus rings (WCAG 2.2 AA, 1.4.3 and 1.4.11).

## Typography

A Font pairs a display face, for the baby's name, the Countdown and headings, with a body face for everything else.
It sets `--font-display`, `--font-display-weight`, `--font-body` and `--font-body-weight`.

<FontTable />

| Token                                   | Value                                          |
| --------------------------------------- | ---------------------------------------------- |
| `--text-xs` to `--text-lg`              | 13, 14, 16 and 18px                            |
| `--text-xl`, `--text-2xl`, `--text-hero` | Grow with the screen, from phone to desktop   |
| `--leading-tight`, `-snug`, `-body`     | 1.1, 1.3 and 1.55                              |
| `--weight-medium`, `--weight-bold`      | 500 and 700                                    |

## Space, shape and motion

| Token                                     | Value                                                     |
| ----------------------------------------- | --------------------------------------------------------- |
| `--space-1` to `--space-8`                | 4, 8, 12, 16, 24, 32, 48 and 64px                          |
| `--gutter`                                | A page's side padding: 16px on a phone, up to 40px         |
| `--content-narrow`, `-medium`, `-wide`    | 480, 720 and 1120px                                        |
| `--radius-sm`, `-md`, `-lg`, `-pill`      | 10, 16 and 24px, and fully round                           |
| `--shadow-sm`, `-md`, `-lg`               | Low, card and floating elevation                           |
| `--control-height`, `--control-height-sm` | 48 and 44px: the tap targets                               |
| `--focus-ring`, `--focus-offset`          | A 3px accent-ink outline, 3px away                         |
| `--duration-fast`, `-base`, `-slow`       | 150, 250 and 600ms; 0 under `prefers-reduced-motion`       |
| `--ease-out`, `--ease-bounce`             | Settle softly, or overshoot and settle for a playful pop   |
