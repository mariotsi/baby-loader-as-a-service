## Agent skills

### Issue tracker

GitHub Issues on mariotsi/baby-loader-as-a-service, via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Design system

UI is built from `src/components/ui`, styled only through tokens. Before building a page read `src/components/ui/docs/UsingComponents.mdx`; before adding or changing a component follow `src/components/ui/docs/NewComponents.mdx`. Browse it all with `npm run storybook`.

### Brand

The Platform is Loading Baby; its logos, favicons and Open Graph images live in `brand/`, generated by `npm run brand` from `scripts/brand-kit.mjs`, which also refreshes the app's copies. Use them; never draw a new mark or edit `brand/` by hand. See "Brand" in `README.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
